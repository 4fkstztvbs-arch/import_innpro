Shoptet → Omega

Prevod exportu vystavených faktúr (Stormware Pohoda XML) na textový import pre KROS Omega. Celý prevod beží priamo v tomto prehliadači — súbor s faktúrami sa nikam neposiela.

⬇ Stiahnuť omega-import.txt
Ako to použiť
  1. V Shoptete: Nastavenia → Export → Faktúry, formát Pohoda XML.
  2. Tu nahraj stiahnutý XML súbor a klikni Prekonvertovať.
  3. Stiahni omega-import.txt.
  4. V Omege: Firma → Import → Import z textového súboru, vyber stiahnutý súbor.

Spoľahlivo je podporená DPH sadzba 23 %. Číslo dokladu v rade sa necháva prázdne (Omega ho dopĺňa sama). Pri prvom použití odporúčame otestovať import v skúšobnej firme v Omege.

Prevod beží lokálne vo vašom prehliadači (JavaScript), žiadne dáta sa nikam needposielajú.
