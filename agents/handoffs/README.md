# Handoffy

Denný záznam každej roly: `RRRR-MM-DD-<rola>.md`. Hlavný agent z nich ráno skladá report a zadania. Šablóna: [_SABLONA.md](_SABLONA.md).

- Rola píše len svoj súbor. Ak v daný deň bežala viackrát, dopíše do toho istého súboru.
- Súbor hlavného agenta (`RRRR-MM-DD-hlavny-agent.md`) obsahuje zadania na deň pre každú rolu. Rola si na začiatku behu prečíta ten najnovší.
- Stručne. Detaily patria do úloh, denníka zmien a experimentov, tu sú len odkazy na ich ID.
- Žiadne tržby, náklady ani údaje o zákazníkoch. Čísla v percentách a v údajoch z vyhľadávania.
- Súbory staršie ako 60 dní môže hlavný agent zmazať, história ostáva v gite.
