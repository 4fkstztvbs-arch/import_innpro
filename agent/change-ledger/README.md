# Change Ledger

Every material agent change should be recorded with at least:

- CHANGE_ID
- DATE
- AREA
- URL/PAGE/SCOPE
- DESCRIPTION
- REASON
- HYPOTHESIS
- BASELINE
- PRIMARY_METRIC
- GUARDRAIL_METRICS
- IMPLEMENTATION
- COMMIT / PR
- EXPERIMENT_ID
- RESULT
- DECISION
- ROLLBACK

Use evidence labels:
- CORRELATION
- LIKELY IMPACT
- EXPERIMENTALLY CONFIRMED

Do not attribute KPI movement to a change without sufficient evidence.
