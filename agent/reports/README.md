# Reporting

## Immediate alert
Use only for material incidents:
- checkout/payment failure
- major conversion drop
- tracking failure
- broken import
- material feed/indexation issue
- regression after deployment

Include:
WHAT HAPPENED / IMPACT / LIKELY CAUSE / CHECKS / ACTION / CURRENT STATUS

## Weekly report
Include:
- executive summary
- sessions
- orders
- conversion rate
- revenue
- gross margin
- revenue/session
- margin/session
- changes deployed
- experiments
- SEO changes/opportunities
- technical health
- findings
- next actions

## Monthly review
Include:
- revenue/order/conversion/margin trends
- channel performance
- SEO growth
- experiment learnings
- technical health
- largest validated opportunities
