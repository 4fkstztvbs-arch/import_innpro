# Reporting

## Immediate alert
Use only for material incidents:
- checkout/payment failure
- major conversion drop
- tracking failure
- broken import
- material feed/indexation issue
- regression after deployment

Include:
WHAT HAPPENED / IMPACT / LIKELY CAUSE / CHECKS / ACTION / CURRENT STATUS

## Weekly report
Include:
- executive summary
- sessions
- orders
- conversion rate
- revenue
- gross margin
- revenue/session
- margin/session
- changes deployed
- experiments
- SEO changes/opportunities
- technical health
- findings
- next actions

## Monthly review
Include:
- revenue/order/conversion/margin trends
- channel performance
- SEO growth
- experiment learnings
- technical health
- largest validated opportunities


## Reporting destinations

Canonical destinations:
- long-term report archive: Google Drive `AI PremiumStore/05 Reports/`
- executive/managerial summaries and material alerts: Slack `#premiumstore-ai`

The Slack channel has been confirmed by the owner as existing and functional.

Do not publish raw customer/order PII, signed export URLs, credentials or other private operational data to Slack or this public GitHub repository. Detailed report artifacts belong in the approved private Drive workspace; Slack should contain concise summaries and links/references where appropriate.
